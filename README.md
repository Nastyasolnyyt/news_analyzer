Микросервисный проект для анализа новостей.
Состоит из 5 сервисов: парсеры (агрегатор, телеграм), предобработка текста, классификация рисков (политический, экономический, социальный), кластеризация событий.
Используется: Python, FastAPI, Kafka, PostgreSQL, Qwen3-VL-30B (через OpenRouter), Docker, Render.com.
Деплой через render.yaml.
Работает на локальной машине и в облаке.
