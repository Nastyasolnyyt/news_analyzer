# Система интеллектуального анализа новостных потоков

Программный комплекс для автоматизированного сбора новостей, идентификации именованных сущностей (NER) и оценки репутационных рисков. Система обеспечивает полный цикл обработки данных: от парсинга веб-ресурсов до визуализации связей между объектами.

## Стек технологий

* **Frontend:** Vue 3 (Composition API), TypeScript, Vite.
* **Backend:** Python 3.11, FastAPI, SQLAlchemy.
* **Database:** PostgreSQL (Cloud: Render).
* **Message Broker:** Apache Kafka (обработка очередей текстов).
* **NLP/ML:** Специализированные библиотеки для извлечения сущностей и анализа тональности.

## Архитектура системы

Проект реализован в виде набора независимых сервисов:
1. **Scraper Service:** Мониторинг источников, указанных в таблице `public.sources`.
2. **Text Preprocessing Service:** Очистка данных и передача сообщений в Kafka.
3. **Analysis Service:** Лингвистический анализ, определение тональности (score) и уровня риска.
4. **API Service:** REST-интерфейс для взаимодействия с фронтенд-частью приложения.

## Структура базы данных

Основные таблицы в PostgreSQL:
* `articles`: Тексты новостей и метаданные (заголовок, ссылка, дата публикации).
* `entities`: Извлеченные объекты (организации, персоны, локации).
* `sentiments`: Результаты оценки эмоциональной окраски текстов.
* `sources`: Реестр ресурсов для парсинга с метками последнего обхода.

## Порядок развертывания

### Настройка серверной части (Backend)
1. Перейти в директорию сервера: `cd backend`.
2. Создать и активировать виртуальное окружение: `python -m venv venv`.
3. Установить зависимости: `pip install -r requirements.txt`.
4. Настроить параметры подключения в файле `.env`.
5. Запустить приложение: `uvicorn main:app --reload`.

### Настройка клиентской части (Frontend)
1. Перейти в директорию клиента: `cd frontend`.
2. Установить зависимости Node.js: `npm install`.
3. Запустить сервер разработки: `npm run dev`.

## Функциональные возможности

* **Мониторинг сущностей:** Автоматическое построение профилей на основе упоминаний в тексте.
* **Оценка тональности:** Количественное измерение рисков (от -1.0 до 1.0).
* **Экспорт отчетов:** Формирование сводных данных в форматах PDF и Excel.
* **Анализ связей:** Визуализация взаимоотношений между выявленными объектами.
