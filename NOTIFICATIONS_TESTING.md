# 📋 Тестирование Уведомлений

## ✨ Новые Функции

### 1. **Поиск по Сущностям** 🔍
- Поле поиска на странице организаций и персон
- Фильтрует список в реальном времени
- Работает по названию (case-insensitive)

### 2. **Корректное Сохранение Настроек** 💾
- Статус уведомлений (Включено/Выключено) теперь сохраняется в БД
- Email адрес сохраняется при клике "Сохранить"
- Выбранные организации и персон сохраняются
- Частота доставки (сразу/ежедневно/еженедельно) сохраняется

### 3. **Управление Триггерами** 🎯
- При выборе организации/персоны создается триггер в БД
- При отключении - триггер отключается (enabled: false)
- Переключения между выбором/невыбором работают безошибочно

## 🧪 Пошаговое Тестирование

### Шаг 1: Включение/Отключение Уведомлений
```
1. Открыть http://localhost:5173/notifications
2. Нажать на кнопку "Включено/Выключено" в верхнем правом углу
3. Статус должен переключиться (визуально + в БД)
4. Нажать "Сохранить настройки"
5. Перезагрузить страницу (F5 или Ctrl+R)
✅ Статус должен остаться тем же
```

### Шаг 2: Сохранение Email
```
1. Ввести email: test@example.com
2. Выбрать частоту: "Ежедневно"
3. Нажать "Сохранить настройки"
4. Перезагрузить страницу
✅ Email и частота должны восстановиться
```

### Шаг 3: Поиск и Выбор Организаций
```
1. В секции "Организации" ввести в поиск: "ПАО" или часть названия
2. Список должен отфильтроваться мгновенно
3. Выбрать одну из них (checkbox)
4. Очистить поиск - должны вернуться все организации
5. Нажать "Сохранить настройки"
6. Перезагрузить страницу
✅ Выбранная организация должна остаться отмеченной
```

### Шаг 4: Поиск и Выбор Персон
```
1. В секции "Персоны" ввести в поиск: "Пу" или "Ле"
2. Список должен отфильтроваться мгновенно
3. Выбрать одну персону
4. Нажать "Сохранить настройки"
5. Перезагрузить страницу
✅ Выбранная персона должна остаться отмеченной
```

### Шаг 5: Полный Цикл
```
1. Включить уведомления
2. Ввести email: your_email@domain.com
3. Выбрать 2-3 организации через поиск
4. Выбрать 1-2 персоны через поиск
5. Установить частоту "Сразу же"
6. Нажать "Сохранить настройки"
   → Должно появиться сообщение "Настройки успешно сохранены!"
7. Перезагрузить страницу
✅ Все должно восстановиться точно так же
8. Отключить уведомления и сохранить
9. Перезагрузить страницу
✅ Уведомления должны остаться отключены
```

## 🐛 Отладка в Console

```javascript

// Вы должны увидеть логи вроде:
// ✅ Settings updated
// ✅ Org trigger 123 created
// ✅ Person trigger 456 updated
// ✅ Email channel created
// ✅ All settings saved successfully
```

### Проверить БД напрямую:
```sql
-- Подключиться к PostgreSQL и проверить:
SELECT * FROM notification_settings WHERE user_id = YOUR_USER_ID;
SELECT * FROM notification_trigger WHERE user_id = YOUR_USER_ID;
SELECT * FROM notification_channel WHERE user_id = YOUR_USER_ID;
```

## 🔄 Проверка Network Requests

1. Открыть DevTools (F12)
2. Перейти на вкладку "Network"
3. Нажать "Сохранить настройки"
4. Должны быть запросы:
   - ✅ `PUT /api/v1/notifications/settings` (200)
   - ✅ `PUT /api/v1/notifications/channels/{id}` или `POST /api/v1/notifications/channels` (200)
   - ✅ `POST /api/v1/notifications/triggers` или `PUT /api/v1/notifications/triggers/{id}` (200+)
