### 🚀 Как это работает

1. **Первая загрузка**:
   - Фронтенд запрашивает `GET /api/v1/entities?page=1&limit=50`
   - Бэкенд возвращает первые 50 сущностей + общее количество
   - Компонент сохраняет в кэш (Map)

2. **Загрузка остальных страниц**:
   - Цикл in `loadEntities()` продолжает загружать `page=2, 3, 4...`
   - Все сущности кэшируются для моментального доступа
   - Поиск работает на кэшированных данных

3. **Навигация**:
   - Кнопки "Предыдущая"/"Следующая" изменяют `currentPage`
   - Vue пересчитывает `filteredEntities` из кэша
   - Нет новых запросов к API (все в памяти)

4. **Поиск**:
   - Фильтр применяется к кэшированным данным
   - Пересчитываются `totalPages` с учетом фильтра
   - Возврат на страницу 1 при изменении поиска
