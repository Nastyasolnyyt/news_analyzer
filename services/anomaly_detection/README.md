# Анализ аномалий в новостных данных (News Anomaly Analyzer)

Система предназначена для автоматизированного обнаружения статистических выбросов в данных мониторинга СМИ. 
Основная задача сервиса — выявление резких всплесков упоминаний объектов и регистрации рисков с применением методов математической статистики.

## Математический аппарат

Для детекции аномалий используется метод межквартильного размаха (Interquartile Range, IQR). 
Данный подход обладает высокой устойчивостью (робастностью) к экстремальным значениям по сравнению с методом Z-score. 

Ключевые особенности реализации:
* **Обработка временных рядов:** для корректного расчета статистических показателей выполняется принудительная реиндексация данных с заполнением отсутствующих дат нулевыми значениями.
* **Фильтрация шума:** установлены минимальные пороги вхождения для исключения ложноположительных срабатываний на малых выборках.

## Технологический стек

* **Язык программирования:** Python 3.10+
* **Библиотеки:** Pandas, NumPy (анализ данных), SQLAlchemy (взаимодействие с СУБД)
* **База данных:** PostgreSQL
* **Среда развертывания:** Docker

## Инструкция по развертыванию

### Локальный запуск
1. Установка зависимостей:
   ```bash
   pip install -r requirements.txt
   ```
2. Настройка параметров подключения в `app/config.py`.
3. Запуск сервиса:
   ```bash
   python app/main.py
   ```

### Сборка и запуск в Docker
1. Сборка образа:
   ```bash
   docker build -t news-analyzer .
   ```
2. Запуск контейнера:
   ```bash
   docker run --name analyzer-instance news-analyzer
   ```

## Режим работы
Сервис функционирует в циклическом режиме. Сбор данных и анализ производятся каждые 10 минут. 
Результаты анализа (тип аномалии, объект, коэффициент отклонения и описание) выводятся в стандартный поток вывода (stdout).
