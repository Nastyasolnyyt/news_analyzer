# 🧪 Инструкция по тестированию новых функций

## 📌 Что было реализовано

### 1️⃣ Создание собственных сущностей
Пользователи могут добавлять свои сущности для отслеживания, даже если они не в БД.

### 2️⃣ Пагинация всех сущностей
Вместо 100 максимум - теперь отображаются **все сущности** из базы с пагинацией.

---

## 🚀 Как запустить и протестировать

### Шаг 1: Убедитесь, что сервисы запущены

```bash
# Из папки проекта
docker-compose up -d

# Проверить статус
docker-compose ps
```

**Должны быть запущены:**
- `postgres` (порт 5432)
- `backend` (порт 8003)
- `redis` (порт 6379)
- `kafka` (порт 9092)

### Шаг 2: Запустите фронтенд (если не запущен)

```bash
cd frontend2
npm install  # Если первый раз
npm run dev
```

Откроется на `http://localhost:5173`

## ✅ Тест 1: Создание новой сущности

### Открыть страницу уведомлений
```
http://localhost:5173/notifications
```

### Найти блоки "Организации" и "Люди"
- Видите карточки с текущими отслеживаемыми сущностями
- Над каждым блоком кнопка "+ Добавить"

### Добавить новую организацию
1. Нажмите "+ Добавить" в блоке **"Организации"**
2. Откроется модальное окно
3. Заполните форму:
   - **Название**: Любое название (например, "Газпром", "Samsung")
   - **Тип**: "Organization" (автоматически)
4. Нажмите "Добавить"

### Ожидаемый результат
✅ Модальное окно закроется
✅ Новая сущность появится в списке отслеживаемых
✅ Чекбокс автоматически отмечен
✅ Сущность сохранена в БД

### Добавить нового человека
1. Нажмите "+ Добавить" в блоке **"Люди"**
2. Заполните форму:
   - **Название**: Имя человека (например, "Иван Петров")
   - **Тип**: "Person" (автоматически)
3. Нажмите "Добавить"

### Ожидаемый результат
✅ Новый человек добавлен
✅ Появляется в списке отслеживаемых

## ✅ Тест 2: Пагинация всех сущностей

### Открыть страницу всех сущностей
```
http://localhost:5173/entities
```

### Проверить загрузку
1. Видите текст "⏳ Загружаем сущности..."
2. Процесс может занять несколько секунд (зависит от количества)
3. Когда загружено, видите список сущностей

### Проверить пагинацию
В конце списка должны быть:
- Кнопка "← Предыдущая" (серая, если на странице 1)
- Текст "Страница X из Y"
- Кнопка "Следующая →" (серая, если на последней странице)

### Навигация между страницами
1. Нажмите "Следующая →"
   - ✅ Страница изменится на 2
   - ✅ Список обновится
   - ✅ Кнопка "← Предыдущая" станет активной
2. Нажмите "← Предыдущая"
   - ✅ Вернетесь на страницу 1
   - ✅ Кнопка "← Предыдущая" станет неактивной

### Проверить поиск
1. В поле поиска введите название сущности (например, "Компания")
2. Список отфильтруется
3. Пагинация пересчитается (может быть меньше страниц)
4. После очистки поиска вернется полный список

## 🔍 Технические проверки

### Проверить API в браузере

Откройте Developer Tools (F12) → Network → нажмите на элемент

**Первая страница:**
```
GET /api/v1/entities?page=1&limit=50
```

**Ответ должен содержать:**
```json
{
  "items": [
    {
      "id": 123,
      "name": "Сущность",
      "entity_type": "Organization",
      "recentMentions": 15,
      "previousMentions": 10,
      "topicCount": 5
    },
    ...
  ],
  "total": 500,
  "limit": 50,
  "page": 1,
  "total_pages": 10
}
```

### Проверить создание сущности

**POST запрос:**
```
POST /api/v1/entities
Body: {"name": "Новая компания", "entity_type": "Organization"}
```

**Ответ (201 Created):**
```json
{
  "id": 999,
  "name": "Новая компания",
  "entity_type": "Organization",
  "created_at": "2024-01-15T10:30:00Z"
}
```

## 🐛 Если что-то не работает

### "Сущности не загружаются"
- [ ] Проверьте, запущена ли БД: `docker-compose ps`
- [ ] Проверьте консоль браузера (F12) на ошибки
- [ ] Проверьте сетевые запросы (Network tab)
- [ ] Перезагрузите страницу (Ctrl+R)

### "Модальное окно не открывается"
- [ ] Проверьте, что вы на странице `/notifications`
- [ ] Очистите кэш браузера (Ctrl+Shift+Delete)
- [ ] Пересобразьте фронтенд: `npm run build`

### "Новая сущность не сохраняется"
- [ ] Проверьте консоль (F12) → Network → POST запрос
- [ ] Проверьте, что БД работает: `docker-compose logs postgres`
- [ ] Проверьте коды ошибок в ответе

### "Пагинация не отображается"
- [ ] Убедитесь, что в БД больше 50 сущностей
- [ ] Проверьте, что `totalPages` > 1 в ответе API
- [ ] Очистите локальное хранилище: F12 → Application → Clear site data
