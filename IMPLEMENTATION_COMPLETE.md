## 🚀 Как использовать

### Для администратора/тестера

```bash
# 1. Убедитесь, что сервисы запущены
docker-compose up -d

# 2. Запустите фронтенд
cd frontend2
npm run dev

# 3. Откройте в браузере
http://localhost:5173
```

### Для конечного пользователя

**Добавить новую сущность**:
1. Перейти на `/notifications`
2. Нажать "+ Добавить" под "Организации" или "Люди"
3. Заполнить форму
4. Нажать "Добавить"
5. ✅ Сущность добавлена и выбрана

**Просмотреть все сущности**:
1. Перейти на `/entities`
2. Использовать кнопки "Предыдущая" и "Следующая"
3. Использовать поиск для фильтрации
4. Нажать на сущность для просмотра профиля

## 📊 API Endpoints

### Получить сущности с пагинацией
```
GET /api/v1/entities?page=1&limit=50
```

**Ответ**:
```json
{
  "items": [
    {
      "id": 1,
      "name": "Компания ABC",
      "entity_type": "Organization",
      "description": "Компания ABC — Organization",
      "recentMentions": 15,
      "previousMentions": 10,
      "topicCount": 5
    }
  ],
  "total": 523,
  "limit": 50,
  "page": 1,
  "total_pages": 11
}
```

### Создать новую сущность
```
POST /api/v1/entities
Content-Type: application/json

{
  "name": "Новая компания",
  "entity_type": "Organization"
}
```

**Ответ (201)**:
```json
{
  "id": 999,
  "name": "Новая компания",
  "entity_type": "Organization",
  "created_at": "2024-01-15T10:30:00Z"
}
```

## ✨ Особенности реализации

✅ **Кэширование на клиенте**: Все загруженные сущности хранятся в `Map` для быстрого поиска
✅ **Локальный поиск**: Фильтрация работает на кэшированных данных без API запросов
✅ **Адаптивный дизайн**: Сетка с автоматической перестройкой для мобильных
✅ **Плавная анимация**: Прокрутка вверх при смене страницы
✅ **Доступность**: Клавиатурная навигация (Enter для открытия профиля)
✅ **Отзывчивый UI**: Кнопки отключаются на границах пагинации

## 🐛 Известные ограничения

1. **Памяти браузера**: При очень большом количестве сущностей (>50000) может быть медленно
   - **Решение**: Добавить virtual scrolling (если нужно)

2. **Имена полей**: API использует camelCase (реcentMentions), БД - snake_case (recent_mentions)
   - **Решение**: Трансформация на уровне сервиса (уже реализована)

3. **Кэширование**: При добавлении новой сущности нужна перезагрузка страницы
   - **Решение**: Добавить кнопку "Обновить" или обновить кэш после создания
